# Tiempos

Минимальный тренажёр спряжения испанских глаголов.

**Времена:** Presente · Pretérito indefinido · Pretérito imperfecto

## Быстрый старт

```bash
npm install
npm run dev        # http://localhost:5173
npm test
npm run build
```

## Как пользоваться

1. Выберите одно или несколько времён и длину сессии (10 / 20 / 30).
2. На карточке — испанское предложение с пропуском `___`, перевод и infinitivo.
3. Впишите форму глагола в пропуск. Enter — проверить; ещё раз Enter — дальше.
4. Ответ проверяется строго (с ударениями); если отличаются только акценты — «почти».

## Стек

Vue 3 + Vite + TypeScript + Vitest. Без бэкенда и без IndexedDB.
