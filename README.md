# Tiempos

Минимальный тренажёр испанского: спряжение глаголов и упражнения по главам учебника.

**Времена:** Presente · Pretérito indefinido · Pretérito imperfecto · Imperativo

Imperativo — утвердительный: tú, usted, nosotros, vosotros, ustedes (формы yo нет).
Глаголы с неестественным императивом (haber, poder, querer, saber, parecer, necesitar,
preferir, sentir, oír, caer, permitir) в нём не тренируются.

## Быстрый старт

```bash
npm install
npm run dev        # http://localhost:5173
npm test
npm run build
```

## Как пользоваться

Внизу три вкладки: **Тренировка**, **Прогресс**, **Таблицы**.

1. Карточка «Что тренируем» на главной показывает текущие настройки — нажмите на неё
   (или на вкладку «Настройки»), чтобы изменить времена, лица, окончания, глаголы,
   режим (умная очередь, только слабые, случайно), длину сессии и способ ответа
   (текстом или устно).
   - Лица можно отключать (usted / ustedes — вместе с él / ellos).
   - «Окончания» -ar / -er / -ir отбирают глаголы по спряжению — и правильные, и неправильные
     (ser, tener — -er; ir, decir — -ir).
2. На карточке — испанское предложение с пропуском, инфинитив в скобках и перевод.
   Предложения собираются под конкретный глагол (comer → «una pizza», ir → «al cine»).
3. Впишите форму глагола в пропуск и нажмите Enter. Верно — сразу следующее задание;
   ошибка — показывается правильная форма и подсказка, Enter — дальше.
   Кнопки `á é í ó ú ñ ü` под полем — для ввода с телефона.
4. Ответ проверяется строго (с ударениями); если отличаются только акценты — «почти».
5. После ошибки — подсказка: правило и таблица форм по лицам (окончания выделены).
   Ошибочная форма вернётся через пару карточек.

## Устный режим

В настройках «Ответ: ⌨ Текст / 🗣 Устно». В устном режиме поля ввода нет:

1. Скажите форму вслух или про себя.
2. Тапните по карточке — появится ответ, правило и таблица форм по лицам.
3. Отметьте себя: «✓ Сказал верно» или «✗ Ошибся» — и сразу следующая карточка.
   Формы с ошибкой вернутся позже, как и в текстовом режиме.

На компьютере: пробел — показать ответ, → — верно, ← — ошибся.
Правописание и ударения тут не проверяются — для них текстовый режим.

## Учебник

Второй раздел тренировки: переключатель **Глаголы / Учебник** наверху главной.
Номер главы = номер юнита источника.

- **Глава = один пул упражнений.** Сейчас 26 глав про местоимения; у каждого пункта есть
  русский перевод.
- **У главы один раздел и массив тегов.** Раздел — большая тема («Местоимения»), теги — подтемы
  внутри него («Личные», «С se», «С императивом»…). В «Настройках» можно отметить весь раздел или
  несколько тем сразу, снять лишние главы или выбрать одну кнопкой «только». Выбор запоминает
  саму тему: новые главы темы подхватятся сами, чужие в неё не попадут.
- **Форматы:** `fill` — вписать ответ в каждый пропуск, у каждого пропуска своё поле (пустое поле
  или «-» — здесь ничего не нужно); `choice` — выбрать вариант; `rewrite` — написать фразу целиком;
  устно — с самооценкой. Варианты ответа заданы отдельно для каждого пропуска.
- **«Мой ответ верный».** Проверка сверяет ответ со списком вариантов, а верных формулировок бывает
  больше. Кнопка появляется после несовпадения: ошибка снимается, ответ засчитывается.
- **Картинки:** нужная панель из учебника, по тапу — на весь экран. Готовые ответы из примеров убраны.
- **Режимы** те же: умная очередь берёт новое по порядку глав, слабым отдаёт до трети сессии,
  тем, у кого подошёл срок повторения, — ещё до трети; прогресс — отдельно от глаголов,
  в `tiempos.book.v2`.

Главы — в `src/data/book/`: `index.ts` собирает `CHAPTERS` и `SECTIONS`, одна глава — файл `uN.ts`
(`unit`, `title`, `ru`, `section`, `tags`, `sets`). Новая глава — новый `uN.ts` и две строки в
`index.ts`; новая тема — ещё и строка в `SECTIONS`, новый раздел — запись там же и значение
в `BookSection`. Картинки — в `public/book/`, имя по номеру упражнения: `12.1-3.jpg`.

Прогресс хранится по номеру набора и месту пункта в нём (`18.2.3`), поэтому текст упражнения
можно править, а новые пункты добавляем только в конец набора.

## Режимы

- **Умная очередь** — до трети сессии гарантированно отдаётся незелёным клеткам «Таблиц»:
  у правильных глаголов учим окончание, а не глагол, поэтому клетка (время × лицо × -ar/-er/-ir)
  берёт столько карточек, сколько ей не хватает до 5 верных подряд, — худшая первой, каждый раз
  другой глагол (сначала с ошибками, потом невиденные и давно не виденные). Нетронутые клетки
  сюда не попадают: новое вводят порции. Ещё до трети — слабым формам вне таких клеток, обычно
  неправильным (не больше 2 показов на форму, сначала те, где больше ошибок); остальное — новое и повторение, выученные — всё реже,
  пока не подойдёт срок: 2 дня после одного верного подряд, каждый следующий удваивает паузу (до 60 дней).
  Новое вводится **порциями** «время × окончание» (indefinido -ar → -er → -ir → следующее время):
  внутри порции все лица и глаголы вперемешку; следующая открывается, когда в текущей по каждому
  лицу есть 2 верных ответа и нет слабых форм. Текущей порции — ~60% сессии, остальное —
  повторение уже открытого. На главной видно, что сейчас новое.
- После ошибки в умном режиме и в «Только слабые» та же форма возвращается через 3 карточки;
  у правильного глагола ещё через 2 — другой глагол той же клетки (то же правило, не та же форма).
- **Только слабые** — только формы, где была ошибка и с тех пор мало верных ответов подряд.
  Планка растёт с числом ошибок в форме: 1–2 ошибки — 2 верных подряд, 3–4 — 3, 5 и больше — 4.
- **Случайно** — равномерно, без учёта прогресса.

## Прогресс

- Экран «Прогресс»: точность, топ слабых форм, сетка глагол × лицо по каждому времени
  (выучена / учу / слабая / не встречалась). Тап по клетке — форма и статистика.
- После сессии: точность, лучшая серия, время, список ошибок.
- В разделе «Учебник» экран показывает прогресс по главам.
- Прогресс хранится в `localStorage`: `tiempos.stats.v1` — по каждой форме верные, ошибки и серия;
  `tiempos.tables.v1` — серия верных подряд по клеткам «Таблиц» (5 подряд — клетка зелёная);
  `tiempos.book.v2` — то же по упражнениям учебника.

## Артикли (отдельная страница)

Кнопка «Артикли» на главной ведёт на `articulos/` — тренажёр и пошаговую схему выбора el / un / Ø
по двум учебникам, плюс схема в PDF. Это готовая статическая страница в `public/articulos/`,
к Vue-приложению она не относится. Собирается в проекте `espanol`:

```bash
cd ../espanol
node scripts/build-trainer.mjs ../tiempos/public/articulos/index.html --standalone
cp docs/algorithm-v2.pdf ../tiempos/public/articulos/
```

## Установка на телефон (PWA)

Откройте сайт в Safari / Chrome → «На экран Домой» / «Установить приложение».
После первого открытия работает офлайн: `vite.config.ts` при сборке генерирует `sw.js`
со списком всех файлов сборки. Картинки учебника лежат в отдельном постоянном кэше,
при обновлении приложения докачиваются только новые.

## Разметка и стили

Классы по БЭМ, у каждого элемента в разметке есть свой класс — его удобно назвать,
когда нужно что-то поменять. Блок = экран или общий компонент:

- экраны: `home`, `settings`, `drill`, `summary`, `progress`, `book-progress`, `tables` — элементы `drill__card`, `drill__answer`, `home__start`…; панель вкладок — `tabbar`;
  блок `drill` разложен по компонентам: `DrillPanel` (экран и состояние), `DrillPrompt` (карточка), `AnswerForm` (ввод), `OralDock` (устный режим);
- общие блоки: `button`, `topbar`, `screen` (`screen__title`, `screen__lead`, `screen__actions`),
  `group`, `choice`, `segmented`, `badge`, `notice`, `stat-tiles`, `form-list`,
  `tabs`, `rule-hint`, `link-button`, `book-picker`, `zoom-image`;
- состояния — модификаторы: `drill__sentence--bad`, `tabs__tab--active`, `progress__cell--weak`.

Элемент обычно несёт и общий, и свой класс (`button button--primary home__start`):
общий задаёт вид, свой — точка для правок конкретного места.

Стили:
- `src/style.css` — дизайн-токены, база (`html`/`body`) и общие блоки (`button`, `group`, `screen`…);
- `<style scoped lang="scss">` в компонентах — стили своего БЭМ-блока (`home__*`, `drill__*`, `tabbar`…).

Дизайн-токены — в начале `src/style.css`, все стили берут значения только из них:

- шрифт — системный (`--font`); размеры `--text-xs … --text-2xl` (12 / 14 / 16 / 20 / 24 / 32)
  и `--text-display` для крупного ответа; насыщенность `--weight-regular / semibold / bold`;
- отступы — сетка 4 px: `--space-1 … --space-7` (4 / 8 / 12 / 16 / 24 / 32 / 48);
- скругления — `--radius-xs` (метки), `--radius-sm` (клавиши), `--radius-md` (карточки), `--radius-pill`;
- цвета — светлая и тёмная тема (`[data-theme]`); янтарный (`--almost`) — только для «почти».

Иконки — `src/components/Icon.vue` (SVG, цвет = цвет текста).

## Версия

Версия — `version` в `package.json`; мелко показывается внизу главной («версия 1.1.0»).
**Каждый коммит, который меняет приложение (код, данные, тексты, стили), обязан повысить версию** —
так по экрану видно, обновился ли телефон. Только README, тесты и инструменты — без повышения.

- **patch** (1.1.0 → 1.1.1) — исправления, правки текстов и данных, мелкие доработки;
- **minor** (1.1.0 → 1.2.0) — новая функция или заметное изменение поведения;
- **major** (1.1.0 → 2.0.0) — сброс или несовместимая миграция сохранённого прогресса.

Повышать командой — она правит и `package.json`, и `package-lock.json`, тег не создаёт:

```bash
npm version patch --no-git-tag-version
```
