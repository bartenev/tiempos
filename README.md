# Tiempos

Минимальный тренажёр спряжения испанских глаголов.

**Времена:** Presente · Pretérito indefinido · Pretérito imperfecto

## Онлайн

https://bartenev.github.io/tiempos/

## Быстрый старт

```bash
npm install
npm run dev        # http://localhost:5173
npm test
npm run build
```

## Как пользоваться

1. Выберите режим, одно или несколько времён и длину сессии (10 / 20 / 30).
2. На карточке — испанское предложение с пропуском `___`, перевод и infinitivo.
   Предложения собираются под конкретный глагол (comer → «una pizza», ir → «al cine»).
3. Впишите форму глагола в пропуск. Enter — проверить; ещё раз Enter — дальше.
   Кнопки `á é í ó ú ñ ü` под полем — для ввода с телефона.
4. Ответ проверяется строго (с ударениями); если отличаются только акценты — «почти».
5. После ошибки — подсказка: основа + окончание и ряд окончаний по лицам
   (для неправильных — вся парадигма). Ошибочная форма вернётся через пару карточек.

## Режимы

- **Умная очередь** — формы с ошибками показываются в ~4 раза чаще новых, выученные — всё реже.
- **Только слабые** — только формы, где была ошибка и ещё нет 2 верных ответов подряд.
- **Случайно** — равномерно, без учёта прогресса.

## Прогресс

- Экран «Прогресс»: точность, топ слабых форм, сетка глагол × лицо по каждому времени
  (выучена / учу / слабая / не встречалась). Тап по клетке — форма и статистика.
- После сессии: точность, лучшая серия, время, список ошибок; серия дней подряд.
- Прогресс хранится в `localStorage`: `tiempos.stats.v1` — по каждой форме верные, ошибки и серия
  (из него же считаются цвета в «Таблицах»: верные − ошибки); `tiempos.daily.v1` — серия дней.

## Установка на телефон (PWA)

Откройте сайт в Safari / Chrome → «На экран Домой» / «Установить приложение».
После первого открытия работает офлайн: `vite.config.ts` при сборке генерирует `sw.js`
со списком всех файлов сборки.

## Стек

Vue 3 + Vite + TypeScript + Vitest. Без бэкенда и без IndexedDB, без PWA-плагинов.
