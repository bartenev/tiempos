# Артикли: данные и алгоритм

Перенесено из проекта `espanol` (папка рядом с tiempos, не под git) — теперь источник правды здесь.

## Откуда задания

Все задания — упражнения из двух учебников, ответы — из ключей учебников (проверены людьми):

| Код | Учебник | Что взято | Пропусков |
|---|---|---|---|
| `GBE` | Gramática básica del estudiante de español (2021) | гл. 5 «Artículos», разделы A–E, с. 30–36, ключи с. 285–286 | 162 |
| `GDU` | Gramática de uso del español A1-B2 (Aragonés, Palencia) | юниты 4–11, с. 16–31, ключи с. 270–271 | 365 |

**id задания = ссылка на учебник:**

- `GBE5-04.2#1` — Gramática básica, глава 5, упражнение 4, пункт 2, пропуск 1 (пункт `0` — образец);
- `GDU7-2.5#1` — Gramática de uso, юнит 7, упражнение 7.2, пункт 5, пропуск 1.

Страница упражнения — поле `page` в `src/data/articles/source/*-articulos.json`.

## Файлы

- `src/data/articles/source/gbe-05-articulos.json`, `gdu-articulos.json` — упражнения: текст пункта с пропусками `{N}`,
  допустимые ответы `accept`, ответ как в ключе `key`. Формат — в блоке `conventions` каждого файла.
- `src/data/articles/source/*-annotations.json` — разметка каждого пропуска: ответы на вопросы дерева
  (конкретный? известен? тип? количество? род, число…) и `why` — почему так.
- `src/data/articles/source/*-annotations-v2.json` — признаки для правил второго учебника (имена, время, ser + профессия…).
- `src/lib/articles/algorithm.ts` — алгоритм v2: особые случаи → ядро → форма. Описание и блок-схемы — [algorithm-v2.md](algorithm-v2.md),
  первая версия (только GBE) — [algorithm.md](algorithm.md).
- `src/lib/articles/build.ts` — из упражнений собирает задания: один пропуск = одно задание,
  остальные пропуски пункта заполнены по ключу; если алгоритм где-то не совпал с ключом — ошибка.
- `src/data/articles/__fixtures__/trainer-v2.json` — задания старой страницы `public/articulos` (эталон);
  тест `src/data/articles.test.ts` сверяет с ним все 527 заданий поле в поле.

Правка текста или ответа — в `source/*.json`; тест сразу покажет, если алгоритм с ключом разошёлся.
